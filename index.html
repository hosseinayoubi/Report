Model comparison

I compared a simple dummy baseline with Logistic Regression, Decision Tree, and Random Forest. Random Forest gave me the best F1 score for the no-show class.

How I would use it

I would keep the use case narrow and low-risk.

  • Send an extra reminder.
  • Ask for confirmation.
  • Offer an easier way to reschedule.
  • Keep a person in the loop.
I would not use a no-show score to cancel appointments, lower a patient's priority, or reduce access to care.

What this project does not prove

  • The data comes from one historical setting.
  • The analysis shows associations, not causal effects.
  • The model needs external validation before real use.
  • Real healthcare data would need strict privacy controls.

If I continued the project, I would test it on newer local data, choose the threshold using real reminder and missed-appointment costs, and keep checking subgroup performance over time.
